# n8n-node-eledo
[![License: Apache 2.0](https://img.shields.io/badge/license-Apache--2.0-green.svg)](https://github.com/TcMenu/tcMenu/blob/main/LICENSE)
[![Eledo](https://img.shields.io/badge/Eledo-green.svg)](https://eledo.online/)

Community n8n node for integrating **Eledo** workflows and PDF automation.

## Status

🚧 **Work in progress**

This repository is under active development.  
The initial goal is to provide a community-maintained n8n node for interacting with the Eledo API.

## Scope (planned)

Depending on Eledo API capabilities, the node may support:

- Triggering Eledo workflows
- Creating PDF documents
- Automating document-related processes
- Integrating Eledo into larger n8n automations

The exact feature set will evolve as development progresses.

## Installation

> Not yet published to npm.

Once released, the node will be installable as a standard n8n community node.
